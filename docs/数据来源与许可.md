# 数据来源与使用许可

本仓库**只包含公开数据的派生结果**，不含任何患者数据、也不含任何 API 密钥。

## 1 数据来源

| 来源 | 内容 | 许可 | 仓库中的文件 |
|---|---|---|---|
| **OpenFDA** `api.fda.gov/drug/label.json` | 美国 FDA 药品说明书（SPL） | 美国政府作品，**公有领域**，可自由使用 | `data/corpus/chunks.jsonl`、`tables.jsonl` |
| **DailyMed**（NLM） | SPL 元数据，用于交叉核对 setid | 美国国立医学图书馆，公有领域 | 不单独存储 |
| **CPIC** `api.cpicpgx.org` | CPIC 基因-药物指南的推荐条目 | CPIC 指南发表于 *Clinical Pharmacology & Therapeutics*（ASCPT/Wiley）；本项目**仅引用推荐原文的短摘要用于非商业教育/演示，并注明出处** | `data/corpus/cpic_chunks.jsonl`、`data/eval/gold_set.jsonl` |

## 2 使用 CPIC 数据的注意事项

- CPIC 是公开的国际指南组织，其 API 与网站面向公众开放，鼓励在临床决策支持中实现；
- 本仓库**不包含** CPIC 指南全文或 PDF，仅包含从 API 提取的推荐条目摘要（306 条，约 200KB）；
- 引用时请标注来源：*CPIC Guideline (cpicpgx.org)，原始论文见各指南的 PMID*；
- **商用前请自行确认授权**（ASCPT 版权）。若需减少风险，可删除 `data/corpus/cpic_chunks.jsonl` 与
  `data/eval/gold_set.jsonl`，改用脚本重新生成：
  ```powershell
  uv run python -m app.scripts.ingest_cpic
  uv run python -m app.scripts.build_cpic_chunks
  ```

## 3 不包含的内容

| 项 | 说明 |
|---|---|
| API 密钥 | `.env` 已被 `.gitignore` 排除；`.env-example` 只含占位符 |
| 患者数据 | 无任何真实患者信息 |
| 原始抓取快照 | `data/raw/` 已排除（可由脚本重建） |
| 向量索引 | `data/index/` 已排除（含 52MB embedding 缓存） |
| NMPA 说明书 | 未获取（地域限制），仓库中无中文说明书 |
