# Demo 演示脚本（3 分钟版）

> 用途：技术演示时按这个顺序走，每步都有可核对的产出。
> 素材：`docs/assets/demo-1-query.png`、`demo-2-result.png`、`demo.gif`

## 0. 准备（提前做好）

```powershell
cd pgx-rag            # 项目根目录
docker compose -f docker/docker-compose.yaml up -d mysql qdrant   # 需要 Docker Desktop
uv run python -m app.scripts.check_services                       # 期望 MySQL / Qdrant / LLM 密钥 ✅
uv run streamlit run app/api/streamlit_app.py                     # http://localhost:8501
```

## 1. 开场（30 秒）——说清"是什么"

> 这是一个**药物基因组学的证据核对工具**：医生/药师已知患者基因型，想知道「这个药能不能用、怎么调」。
> 输入「药 + 基因型 + 临床场景」，输出一张证据卡：**RAG 答案（通俗、逐句引用）** + **CPIC 指南标准答案** + **两者是否一致**。
> 数据只用两个公开源：FDA 说明书（2416 切片）+ CPIC 指南（247 条推荐）。

## 2. 演示"正常路径"（60 秒）

左侧选择：药物 `clopidogrel`、基因 `CYP2C19`、表型 `Poor Metabolizer`、场景 `CVI ACS PCI` → 点「生成」。

指给观众看三处：

| 位置 | 说明 |
|---|---|
| 左栏证据等级 | 🟢 **A 级**：6 条证据来自黑框警告/剂量/禁忌等核心章节，且含目标基因 |
| 左栏答案 | 结论 + 依据，**每句带 `[n]`**；点开「引用原文」能核对英文原文与 set_id |
| 右栏 | CPIC **Strong** 级：*Avoid clopidogrel if possible. Use prasugrel or ticagrelor…*，并标注三个场景的强度差异（ACS/PCI=Strong，非 ACS=Moderate） |

一句话点评：**左边是"人话版"，右边是"标准答案"，中间的一致性判定告诉你两者有没有冲突。**

## 3. 演示"失败路径"（60 秒，这段最加分）

换成：药物 `simvastatin`、基因 `SLCO1B1`、表型 `Decreased Function` → 生成。

指给观众看：

- 右栏：CPIC **A 级**推荐「换用其他他汀；若必须用辛伐他汀，剂量限制 <20 mg/日」；
- 左栏说明书侧：**说明书未收录该基因** → 自动降级，改为给该药的通用肌病/CK 监测段落，并明确标注「不能作为基因型依据」；
- 一致性：`说明书未收录该基因`。

一句话点评：**60 个 FDA 候选标签里 SLCO1B1 出现 0 次**，只有 CPIC 有——这就是为什么要双源。
（实测：17 个药里有 2 个药的说明书完全没有目标基因。）

## 4. 演示"拒答"（30 秒）

命令行跑一条：

```powershell
uv run python -m app.scripts.ask "SLCO1B1 变异的人吃辛伐他汀会肌痛吗？" --no-graph
```

看输出：证据等级 **D** → **拒答**，并说明「检索到的 6 条都没有提及 SLCO1B1，该药基因证据可能只存在于 CPIC 指南」。
耗时约 **0.24 秒**——因为 D 级直接拒绝，**不调用大模型**。

一句话点评：**护栏不依赖模型是否听话，而是先用确定性规则判证据。**

## 5. 收尾：数字与边界（30 秒）

| 指标 | 值 |
|---|---|
| 语料 | 2722 切片（说明书 2416 + 指南 306）/ 178 张表 |
| 检索 | R@5 = 1.000、MRR = 0.929（7 问评测） |
| 核心评测 | 80 题 CPIC 金标准，方向一致率 **86.5%** |
| 拒答 | 0.24s，0 次误答 |

**主动说边界**（比被问出来强）：
1. 86.5% 是与 CPIC 推荐方向的**一致率**，且 CPIC 原文已在语料里 —— 衡量的是"能否正确检索并转述权威依据"，不是独立医学推理；
2. 还没有药师盲评，这是下一步；
3. 只有 17 个药；NMPA 中文说明书因地域限制暂时拿不到。

## 6. 常见问题 & 备选答案

| 问题 | 答法 |
|---|---|
| 为什么不用 ES？ | 2416 条规模下自写 BM25 建索引 <1s、查询 <10ms，且能精确控制基因/等位基因分词；ES 已写进编排，规模上来再切 |
| 为什么不用 bge-m3？ | 本机无 GPU、装 torch 受阻，先用 DashScope 1024 维多语言 embedding；代码已做成双后端，TEI 一起来就能切 |
| 重排为什么关掉？ | 实测 gte-rerank 把 MRR 从 0.929 拉到 0.707，调参记录在 `reports/stage2_retrieval.md` |
| 怎么防幻觉？ | 三道：证据分级前置（D 级不调模型）、逐句引用回填与越界检查、数字一致性校验（待补） |
