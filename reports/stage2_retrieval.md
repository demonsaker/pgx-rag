## 1 链路

```
中文问题
  └─ 术语桥：中文药名/表型/剂量词 → 说明书英文说法（可枚举的领域词，不做机器翻译）
       ├─ BM25（精确命中：基因符号、等位基因、剂量词）
       └─ 向量（text-embedding-v4，1024 维，直接用中文原文）
            └─ RRF 融合 → 单药过滤 → 章节权威度惩罚 → top-k
```

三个关键设计：

1. **两路都要**：BM25 抓 `HLA-B*5701`、`300 mg`、`CYP2C19` 这类精确符号；向量抓语义改写。
2. **融合用 RRF 而不是加权求和**：余弦相似度 0–1，BM25 0–∞，量纲不同，直接相加是错的。
3. **等位基因写法归一**：`HLA-B*57:01` 与 `HLA-B*5701` 在分词时统一去冒号，避免纯格式差异导致漏召回。

## 4 重排为什么默认关闭（完整调参记录）

保留这段是因为「测过才发现没用」比「假设有用」更值得写：

| 做法 | MRR | 观察 |
|---|---|---|
| 中文问句直接重排 | 0.619 | 分数挤在 0.15–0.33，把患者版说明书排第一、黑框警告排第七 |
| 改用术语桥英文词项重排 | 0.707 | 分数升到 0.66–0.82，但词项堆丢了问句意图 |
| 改成干净英文问句重排 | 0.714 | 单条可命中，整体仍不如不重排 |
| 重排分与 RRF 按 α 融合 | α=0.3→0.833 / 0.5→0.786 / 0.7→0.714 | 只要掺入重排分就单调下降 |
| **不重排（RRF + 权威度惩罚）** | **0.929** | 采纳 |

**原因分析**：本语料里「切题」与「权威」不是一回事——患者版说明书用大白话复述了黑框警告，
cross-encoder 更容易给它打高分；gte-rerank 对跨语言和章节权威度都不敏感。
真正有效的三件事是：**RRF 融合、章节优先级惩罚、单药过滤**。
