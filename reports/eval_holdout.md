# 留出实验：把「指南原文」从语料里拿掉，再考一次

> 目的：检验 86.5% 到底测的是什么。
> 结论：**同一批题，语料里有指南原文时 88.6%，把指南切片剔除后掉到 54.2%。**
> 复现：
> ```powershell
> # 对照组（题目限定这 4 个药，语料不剔除）
> uv run python -m app.scripts.eval_gold --holdout-drugs clopidogrel,azathioprine,carbamazepine,phenytoin --no-exclude
> # 留出组（把这 4 个药的 182 条 CPIC 切片从候选里剔除）
> uv run python -m app.scripts.eval_gold --holdout-drugs clopidogrel,azathioprine,carbamazepine,phenytoin
> ```

## 1 实验设计

| 项 | 说明 |
|---|---|
| 题目 | 42 道（来自 CPIC 金标准，集中在 4 个药：氯吡格雷 / 硫唑嘌呤 / 卡马西平 / 苯妥英） |
| 对照组 | 语料完整（2722 条，含 306 条 CPIC 切片），题目不变 |
| 留出组 | 把这 4 个药的 **182 条 CPIC 切片**从检索候选中剔除（说明书切片保留） |
| 判定 | 与之前一致：LLM 盲判方向，与 CPIC 金标准比对 |

## 2 结果

| 指标 | 对照组（含指南） | 留出组（剔除指南） | 差值 |
|---|---|---|---|
| 一致 | 31 | 13 | −18 |
| 不一致 | 4 | 11 | +7 |
| 方向不明 | 7 | **18** | **+11** |
| **方向一致率** | **88.6%** | **54.2%** | **−34.4pp** |

## 3 怎么解读

1. **86.5%（全量 80 题）主要测的是「检索 + 转述」**。
   把指南原文放回语料，系统能找到并正确转述；拿掉之后，同样的题它有一半给不出方向。
2. **系统没有"硬编"答案**。
   留出组里「方向不明」从 7 涨到 18——面对没有指南依据的表型问题，它更多地说"说明书未定义该表型"，
   而不是编一个方向。这是**保守行为**，比"错答"好。
3. **这也反过来证明双源的必要性**。
   说明书不使用 CPIC 的表型命名（Intermediate/Normal Metabolizer），只靠标签答不出这类问题——
   这正是当初把指南原文纳入语料的理由（方向不明从 48/85 降到 7/85）。
4. **指标要改名字**。
   - **转述一致率**（88.6% / 86.5%）：语料含金标准来源时的检索+转述能力；
   - **留出一致率**（54.2%）：拿掉金标准来源后的泛化能力。
   两个数字都真实，但含义不同，对外说明必须分开写。

## 4 这个实验的局限

- 只留出了 4 个药、42 题，样本偏小；
- 留出组里"方向不明"的 18 条，本可以进一步细分「说明书确实没写」与「写了但没用 CPIC 措辞」——
  前者应触发拒答，后者说明需要表型归一（已加入同义词扩展，但覆盖不全）；
- 没有回答「答案是否被引用原文支撑」——那是下一步的**引用忠实度**指标（不循环）。
